## What I Build

I build **complete AI systems** — not demos, not notebooks. Every project I ship has a React frontend, a FastAPI backend, and an AI layer that does something genuinely useful. My work spans three domains:

- 🏢 **Enterprise automation** — AI that reads, understands, and compares vendor proposals

### 📄 Smart RFP System
**AI Procurement Platform**

Automates the full vendor proposal lifecycle. Upload an RFP PDF, submit vendor proposals, get an AI-generated comparison matrix with radar charts and scored rankings.

**The hard part:** Structured extraction from unstructured PDFs at scale, with vendor data aligned row-by-row for fair comparison.

`GPT-4o` `ChromaDB` `text-embedding-3-large` `FastAPI` `React` `SQLite` `ApexCharts`

> Groq fallback built in — it keeps running if OpenAI is down.

### 🚌 VRP Optimizer
**Multi-Depot Route Planner**

Solves employee transport routing (multi-depot → factory) using a Genetic Algorithm with a deterministic feasibility decoder. Routes use **real road distances** via OSRM, not straight lines.

**The hard part:** Heterogeneous fleet (owned + rented), shift constraints, capacity enforcement, and OSRM caching for performance.

`Python` `FastAPI` `React` `OSRM` `Genetic Algorithm` `Folium` `Leaflet.js`

> Dual interface: CLI for engineers, web UI for operations teams.

[![Repo](https://img.shields.io/badge/View%20Repo-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/SaimKhalid388/VRP)

</td>
<td width="33%" valign="top">

### 🥐 Bakery Chat
**Domain-Specific RAG Chatbot**

Full-stack conversational AI for a bakery business. Handles menu queries, FAQs, and location questions with a complete RAG pipeline — not prompt stuffing.

**The hard part:** Hybrid retrieval (FAISS vector search + Whoosh full-text), reranking, multi-turn session memory.

`Python` `FastAPI` `React` `FAISS` `Whoosh` `Groq API` `Pydantic` `Uvicorn`

> Two retrieval engines combined beat either one alone.

[![Repo](https://img.shields.io/badge/View%20Repo-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/SaimKhalid388/BAKERY-CHAT)
